# Zomentum

> Zomentum is an AI-powered revenue platform for managed service providers (MSPs) and IT service businesses, unifying proposals and quotes, contracts and e-signatures, an MSP-focused CRM, workflow automation, and integrated payment collection. It exposes a REST API (documented via Postman) that uses Bearer token authentication backed by Auth0, available on the Growth plan.

## API

- [Zomentum API Documentation](https://api-docs.zomentum.com): Public Postman documentation for the Zomentum REST API (base host: https://api.zomentum.com).
- [Generating an API User](https://help.zomentum.com/support/solutions/articles/44002337023-generating-an-api-user): How to create an API User, generate access/refresh tokens, and authenticate.

## Authentication

- Bearer token (Authorization: Bearer <token>); Auth0-issued access + refresh tokens; API User provisioned in dashboard Settings; Growth plan required.
- [Authentication profile](authentication/zomentum-authentication.yml)
